MaliPen'i Kur ve Başla

Platformunu seç, adım adım rehberi takip et — 2 dakikada çizmeye başla.

1
Uygulamayı Applications'a Taşı Zorunlu
DMG dosyasını açtıktan sonra MaliPen ikonunu sürükleyerek Applications klasörüne bırak.
🖊
MaliPen.app
Sürükle
Applications
2
"Doğrulanamıyor" Uyarısını Kaldır Zorunlu
macOS, Apple Developer hesabı olmayan uygulamalara güvenlik uyarısı gösterir. Terminal'de bir komutla bu kısıtlamayı kaldır.
Terminal — zsh
~ $
3
Sistem İzinlerini Ver Zorunlu
MaliPen ekrana çizim yapabilmek için iki sistem izni gerektirir. Bunları bir kez verirsen bir daha sorulmaz.
🎬
Ekran Kaydı (Screen Recording)
Sistem Tercihleri → Gizlilik ve Güvenlik → Ekran Kaydı → MaliPen ✓
♿
Erişilebilirlik (Accessibility)
Sistem Tercihleri → Gizlilik ve Güvenlik → Erişilebilirlik → MaliPen ✓
Terminal — Ayarları hızlı aç
# Ekran Kaydı ayarlarını doğrudan aç:
~ $
4
Uygulamayı Başlat Hazır!
Launchpad'den veya Applications klasöründen MaliPen'i aç. Araç çubuğu ekranında belirince çizmeye başlayabilirsin.
Terminal — veya terminal ile başlat
~ $
MaliPen'i İndir
macOS 12+ • Apple Silicon ve Intel • Ücretsiz
İndirme başlamazsa GitHub Releases'e git.
1
SmartScreen Uyarısını Geç Zorunlu
Windows, bilinmeyen yayıncıdan gelen uygulamalara SmartScreen uyarısı gösterir. "Daha fazla bilgi" → "Yine de çalıştır" adımlarını uygula.
Windows Güvenlik ✕
🛡️
Windows PC'nizi korudu
Microsoft SmartScreen bu uygulamayı tanımıyor.
2
Kurulum Sihirbazını Çalıştır Zorunlu
EXE dosyasını çalıştır. Kurulum yolunu seçebilirsin — varsayılan olarak %LOCALAPPDATA%\MaliPen kullanılır.
🖊
MaliPen-windows.exe
Çalıştır
Windows'a Kur
3
Sorun Varsa: PowerShell ile Çalıştır Opsiyonel
Uygulama başlamazsa PowerShell'i Yönetici olarak aç ve aşağıdaki komutu çalıştır.
PowerShell (Yönetici)
# Execution Policy ayarla (bir kez yeter):
PS C:\>
4
UAC İznini Onayla ve Başlat Hazır!
MaliPen başlarken UAC (Kullanıcı Hesabı Denetimi) uyarısı çıkabilir. "Evet" seçerek devam et. Güvenlik Duvarı uyarısında ise "Erişime izin ver"i seç.
🔐
UAC İzni
"Bu uygulamanın değişiklik yapmasına izin vermek istiyor musunuz?" → Evet
🛡️
Windows Güvenlik Duvarı
Uyarı çıkarsa → "Erişime izin ver" seç
